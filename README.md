# Hospital Operations Analysis Dashboard

## Project Overview
Hospital Operations Analysis is a Power BI project designed to analyze hospital admissions, bed utilization, doctor-related information, and patient discharges. It uses interactive dashboards to help users explore operational trends and identify patterns in hospital data.

## Objectives
- Analyze hospital admission trends.
- Compare admissions across departments.
- Examine length of stay and discharge patterns.
- Monitor bed and hospital resource utilization.
- Present key operational indicators through interactive visualizations.

## Tools and Technologies
- Microsoft Power BI
- Power Query (M)
- DAX (Data Analysis Expressions)
- Microsoft Excel

## Key Insights
The dashboard can be used to explore department-wise admissions, length of stay, monthly admission patterns, and open patient records. Refer to the dashboard for the actual results and insights.

## How to Use
1. Download or clone this repository.
2. Open the Excel dataset if you want to inspect the source data.
3. Open `PowerBI/Hospital_Operations_Analysis.pbix` using Microsoft Power BI Desktop.
4. If prompted, update the dataset source path.
5. Refresh the data and explore the report pages.

## Project Files
- **Dataset:** Excel source data.
- **PowerBI:** Power BI report, DAX measures, Power Query code, theme and validation measures.
- **Screenshots:** Dashboard previews.
- **Report:** Project documentation.

## Data Disclaimer
Check the dataset documentation before reuse. If the dataset is synthetic, it should not be interpreted as actual hospital or patient records.
